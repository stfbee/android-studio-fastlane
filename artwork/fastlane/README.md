# Fastlane logo sources

- `favicon.ico`: original requested asset from [fastlane/docs](https://github.com/fastlane/docs/blob/master/docs/img/favicon.ico).
- The ICO is byte-for-byte identical to [fastlane/fastlane.tools/source/images/favicon.ico](https://github.com/fastlane/fastlane.tools/blob/master/source/images/favicon.ico).
- `fastlane.svg`: SVG supplied by the user, carrying SVG Repo metadata. Its five paths and colors match [gilbarbara/logos/logos/fastlane.svg](https://github.com/gilbarbara/logos/blob/main/logos/fastlane.svg); that collection's CC0 dedication is preserved in `VECTOR-LICENSE.txt`.

The plugin resources reuse the supplied SVG paths and colors unchanged. Only canvas size and transparent padding differ: 40×40 for `META-INF/pluginIcon.svg` and 16×16 for `icons/fastlaneFile.svg`.

The Fastlane name and logo identify the supported technology; this plugin is an independent integration.
